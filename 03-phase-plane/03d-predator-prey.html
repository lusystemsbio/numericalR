3D. Modeling predator-prey dynamics

Author

Mingyang Lu

This chapter models a predator-prey system, a cornerstone example of how populations regulate one another in an ecosystem (Carroll 2016), with the classic Lotka-Volterra equations (Lotka 1925; Volterra 1926; Sontag 2026). Unlike the toggle switch and chemostat of Part 3A through Part 3C, where every trajectory settled onto a fixed point, this system oscillates: its trajectories form closed orbits around a center. That difference reshapes the analysis, so beyond reusing the phase-plane tools we also look at what a center means for stability and, at the end, how to fit the model’s parameters to real population data. The general derivations (RK4, vector fields, the Jacobian stability test) are only referenced here; see Parts 3A and 3B for them.

3D.1 Lotka-Volterra model

Let \(N\) be the prey population and \(P\) the predator population. The model is

\[\begin{equation} \begin{cases} \dfrac{dN}{dt} = f(N, P) = N\,(a - bP) \\[2mm] \dfrac{dP}{dt} = g(N, P) = P\,(cN - d) \end{cases} \tag{1} \end{equation}\]

Prey grow exponentially at rate \(a\) and are eaten at a rate \(bP\) proportional to the predator level; predators die off at rate \(d\) and reproduce at a rate \(cN\) set by the available prey. All four parameters are positive. Throughout we take \(a = d = 1\), \(b = 0.03\), and \(c = 0.02\).

3D.2 Oscillations and closed orbits

With predators absent (\(P = 0\)) the prey equation reduces to \(dN/dt = aN\), pure exponential growth; with prey absent (\(N = 0\)) the predators decay as \(dP/dt = -dP\). When both are present the two populations chase each other and the levels oscillate in time. In the phase plane this shows up as closed orbits: starting from different initial conditions traces a family of nested loops, none of which spirals in or out. This is the signature of a conservative (center-type) system and is qualitatively different from the attractor dynamics of Parts 3A-3C.

R implementation

derivs_LV <- function(t, Xs, a, b, c, d) {   # Lotka-Volterra: prey N, predator P
  N <- Xs[1]; P <- Xs[2]
  c(N * (a - b * P), P * (c * N - d))
}

# generic multi-variable RK4 (same as Part 3A)
RK4_generic <- function(derivs, X0, t.total, dt, ...) {
  t_all <- seq(0, t.total, by = dt); n_all <- length(t_all)
  X_all <- matrix(0, n_all, length(X0)); X_all[1, ] <- X0
  for (i in 1:(n_all - 1)) {
    t0 <- t_all[i]
    k1 <- dt * derivs(t0,          X_all[i, ],          ...)
    k2 <- dt * derivs(t0 + dt / 2, X_all[i, ] + k1 / 2, ...)
    k3 <- dt * derivs(t0 + dt / 2, X_all[i, ] + k2 / 2, ...)
    k4 <- dt * derivs(t0 + dt,     X_all[i, ] + k3,     ...)
    X_all[i + 1, ] <- X_all[i, ] + (k1 + 2 * k2 + 2 * k3 + k4) / 6
  }
  cbind(t_all, X_all)
}

3D.3 Nullclines and steady states

The nullclines follow directly from Equation (1). The N-nullcline (\(dN/dt = 0\)) is \(N = 0\) or \(P = a/b\); the P-nullcline (\(dP/dt = 0\)) is \(P = 0\) or \(N = d/c\). Each nullcline is therefore a pair of straight lines. A steady state requires both derivatives to vanish, so only crossings between an N-nullcline line and a P-nullcline line count (two lines from the same nullcline crossing do not). That gives two steady states, \(X_1 = (0, 0)\) and \(X_2 = (d/c, a/b)\). Below we draw the unit vector field (as in Part 3A), overlay the four nullcline lines and the two steady states, and add one orbit.

3D.4 Stability: a saddle and a center

Perturbing each steady state slightly (keeping \(N, P \geq 0\)) reveals two very different behaviors. Near \(X_1 = (0, 0)\) the trajectory swings away, so \(X_1\) is unstable. Near \(X_2 = (d/c, a/b) = (50, 33.3)\) the trajectory loops around the point on a closed orbit without approaching or leaving it, the defining feature of a center.

The same conclusion follows from the Jacobian eigenvalues, using the numerical stability classifier of Part 3B (redefined here so the chapter runs on its own). \(X_1\) has real eigenvalues of opposite sign, a saddle (code 3). \(X_2\) has a pure imaginary pair, the mark of a center. Note the numerical classifier reports code 5 (unstable spiral) for \(X_2\): finite- difference noise nudges the zero real part slightly positive, and linear analysis alone cannot separate a true center from a very weak spiral. The closed orbits of 3D.2 are what confirm it is a genuine center.

R implementation

# numerical-Jacobian stability classifier (same as Part 3B)
stability_2D <- function(derivs, ss, ...) {
  delta <- 0.001
  f0  <- derivs(0, ss, ...)
  fdx <- derivs(0, ss + c(delta, 0), ...)
  fdy <- derivs(0, ss + c(0, delta), ...)
  jacobian <- matrix(c((fdx[1] - f0[1]) / delta, (fdx[2] - f0[2]) / delta,
                       (fdy[1] - f0[1]) / delta, (fdy[2] - f0[2]) / delta), 2)
  lambda <- eigen(jacobian)$values
  if (is.complex(lambda)) {
    if (Re(lambda[1]) < 0) 4 else 5
  } else if (lambda[1] < 0 && lambda[2] < 0) 1
  else if (lambda[1] >= 0 && lambda[2] >= 0) 2 else 3
}

ss_all <- rbind(c(0, 0), c(d / c, a / b))
ss_stab <- t(apply(ss_all, 1, function(ss) c(ss, stability_2D(derivs_LV, ss, a, b, c, d))))
colnames(ss_stab) <- c("N", "P", "Stability")
ss_stab   # 3 = saddle (X1); 5 = center reported as unstable spiral (X2)
      N        P Stability
[1,]  0  0.00000         3
[2,] 50 33.33333         5

Python implementation

# numerical-Jacobian stability classifier (same as Part 3B)
def stability_2D(derivs, ss, **kw):
    delta = 0.001
    f0  = derivs(0, ss, **kw)
    fdx = derivs(0, ss + np.array([delta, 0]), **kw)
    fdy = derivs(0, ss + np.array([0, delta]), **kw)
    J = np.array([[(fdx[0] - f0[0]) / delta, (fdy[0] - f0[0]) / delta],
                  [(fdx[1] - f0[1]) / delta, (fdy[1] - f0[1]) / delta]])
    lam = np.linalg.eigvals(J)
    if np.any(np.iscomplex(lam)):
        return 4 if np.real(lam[0]) < 0 else 5
    if lam[0] < 0 and lam[1] < 0:
        return 1
    return 2 if lam[0] >= 0 and lam[1] >= 0 else 3

ss_all = np.array([[0, 0], [d / c, a / b]])
for ss in ss_all:
    print(ss, "-> stability", stability_2D(derivs_LV, ss, **par))
[0. 0.] -> stability 3
[50.         33.33333333] -> stability 5
# 3 = saddle (X1); 5 = center reported as unstable spiral (X2)

3D.5 The lynx-hare data

To ground the model in data, we fit its parameters \(a, b, c, d\) to real populations: the Hudson’s Bay Company fur-trade records of snowshoe hare and Canada lynx from 1900-1920, a classic predator-prey series discussed in both Carroll (2016) and Sontag (2026). Both populations rise and fall in a coupled roughly ten-year cycle, the lynx peaks trailing the hare peaks, the same qualitative pattern the model produces. We first look at the data as time courses and as a trajectory in the phase plane, then fit it two ways in the following sections.

3D.6 Fitting by error minimization

Error minimization simulates the model for a trial parameter set, measures the sum of squared differences (SSD) between the simulated and observed levels, and adjusts the parameters until the SSD is as small as possible. The minimizer (R’s Newton-based nlm, or scipy.optimize.minimize with BFGS) finds only a local minimum, so it needs a reasonable starting guess; here we begin from a hand-picked one. The fitted trajectory follows both the time courses and the phase-plane loop of the data.

# minimize the SSD between simulated and observed levels with nlm.
# a, b, c, d are forwarded to derivs_LV through RK4_generic's `...` ellipsis; pass them
# positionally, since a named `d=` would partial-match the derivs/dt formals and error out.
data_LV <- cbind(lvdata$hare, lvdata$lynx)
cal_error <- function(p, nsteps = 10) {
  sim <- RK4_generic(derivs_LV, data_LV[1, ], nrow(data_LV) - 1, 1 / nsteps,
                     p[1], p[2], p[3], p[4])
  sim <- sim[seq(1, nrow(sim), by = nsteps), 2:3]
  sum((data_LV - sim)^2)
}
p0 <- c(0.5, 0.02, 0.02, 0.5)                      # hand-picked initial guess
p_fit <- setNames(nlm(cal_error, p0)$estimate, c("a", "b", "c", "d"))

# minimize the SSD between simulated and observed levels.
# scipy.optimize.minimize with BFGS is the counterpart of R's Newton-based nlm;
# a derivative-free method (Nelder-Mead) can stall at a poor local minimum here.

3D.7 Fitting by linear regression

Linear regression exploits a special feature of this model: the rate equations are linear in the parameters. Replacing the time derivatives with centered finite differences at each year turns Equation (1) into a linear system, for the prey \(\frac{N_{t+1} - N_{t-1}}{2} = a\,N_t - b\,N_t P_t\) and similarly for the predator, which ordinary least squares solves directly (no intercept). It is exact only for closely spaced data, so on the sparse yearly record the fit is rougher than error minimization. It is deterministic and cheap, though, which makes it an excellent starting guess for the error minimization (Practice Q5).

# centered finite differences make Eq (1) linear in the parameters.
# np.linalg.lstsq is the counterpart of R's lm(... - 1) (no intercept).
N = lvdata["hare"].to_numpy(); P = lvdata["lynx"].to_numpy(); tot = len(N); mid = slice(1, tot - 1)

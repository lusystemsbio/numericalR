6B. Brownian motion

Author

Mingyang Lu

Brownian motion, the erratic wandering of a particle buffeted by random kicks, is the prototypical stochastic process and the foundation for the stochastic differential equations of the following chapters. We build it up from a simple one-dimensional random walk, study the statistics of an ensemble of walks, and arrive at the Wiener process.

6B.1 A one-dimensional random walk

A particle starts at the origin, \(x(0) = 0\). At each time step it hops left or right by a fixed distance \(\Delta x\), with equal probability. We write two implementations: one with an explicit loop (like an ODE integrator) and one using only vector operations. The vectorized version is concise but less flexible for more complex dynamics; both give statistically identical walks.

NoteRecipe 6B.1.1

Objective. Simulate an ensemble of one-dimensional random walks and see how they spread.

Model. A walker starts at 0 and at each step moves +dx or -dx with equal probability, x_next = x + dx*(+-1).

Method. A discrete symmetric 1D random walk, written as an explicit loop and as a cumulative sum of random steps.

Test. dx = 1, dt = 1, 1000 steps, 1000 independent walks; seed 12.

Show. A plot of several random-walk trajectories versus time.

Verification. Each walk wanders differently, but as a group they spread symmetrically about the origin.

R implementation

# 1D random walk, explicit loop
brownian <- function(t.total, dt, dx) {
  t_all <- seq(0, t.total, by = dt)
  n_all <- length(t_all)
  x_all <- numeric(n_all)          # starts at 0
  for (i in 1:(n_all - 1)) {
    x_all[i+1] <- x_all[i] + dx * sample(c(-1, 1), size = 1)
  }
  return(cbind(t_all, x_all))
}

# 1D random walk, vectorized (cumulative sum of random +/- steps)
brownian_concise <- function(t.total, dt, dx) {
  t_all <- seq(0, t.total, by = dt)
  x_all <- cumsum(sample(c(-1, 1), size = length(t_all), replace = TRUE)) * dx
  return(cbind(t_all, x_all))
}

set.seed(12)
t.total <- 1000; dt <- 1; dx <- 1; nrep <- 1000   # nrep independent walks
results_bm_1d <- replicate(nrep, brownian(t.total, dt, dx))   # array [time, 2, rep]

plot(NULL, xlab = "t", ylab = "x", xlim = c(0, 1000), ylim = c(-70, 70))
for (i in 1:10) lines(results_bm_1d[,1,i], results_bm_1d[,2,i], col = i)   # first 10 walks

import numpy as np
import matplotlib.pyplot as plt

# 1D random walk, explicit loop
def brownian(t_total, dt, dx):
    t_all = np.arange(0, t_total + dt, dt)
    n_all = len(t_all)
    x_all = np.zeros(n_all)          # starts at 0
    for i in range(1, n_all):
        x_all[i] = x_all[i-1] + dx * np.random.choice([-1, 1])
    return np.column_stack((t_all, x_all))

    x_all = np.cumsum(np.random.choice([-1, 1], size=len(t_all))) * dx
    return np.column_stack((t_all, x_all))

6B.2 Statistics of the ensemble

Across many walks the mean position stays at zero while the spread grows with time. At any fixed \(t\) the distribution of \(x\) is (exactly) binomial and, after many steps, approaches a Gaussian by the central limit theorem, with a width that widens as \(t\) increases. Theory gives the variance \(\langle x^2 \rangle = 2 D t\), with the one-dimensional diffusion constant (Einstein 1905)

\[ D = \lim_{\Delta t \rightarrow 0} \frac{\Delta x^2}{2 \Delta t} . \tag{3} \]

We view the spread with a box plot across sampled times, confirm the Gaussian shape with histograms at a few times, and check the variance against the theory. For our steps (\(\Delta x = \Delta t = 1\)), \(D = 0.5\), so \(\langle x^2 \rangle = t\).

6B.3 Gaussian move steps

Nothing forces the steps to be discrete \(\pm \Delta x\). Drawing each step from a Gaussian of mean \(0\) and standard deviation \(\Delta x\) gives the same large-scale statistics.

NoteRecipe 6B.3.1

Objective. Repeat the random walk with continuous Gaussian steps and compare the spread to discrete steps.

Model. The same 1D walk, but each step is drawn from a Gaussian of mean 0 and standard deviation dx, x_next = x + N(0, dx).

Method. A 1D random walk with Gaussian-distributed step sizes.

Test. dx = 1, dt = 1, 1000 steps, 1000 walks; seed 12; the spread compared at times 1, 101, …, 901.

Show. A box plot of the walker positions at sampled times, next to the discrete-step walk.

Verification. The spread is statistically identical to the discrete-step walk, so the step distribution does not matter for the long-time behavior, only its mean and variance.

R implementation

brownian_gaussian_steps <- function(t.total, dt, dx) {
  t_all <- seq(0, t.total, by = dt)
  n_all <- length(t_all)
  x_all <- numeric(n_all)
  for (i in 1:(n_all - 1)) {
    x_all[i+1] <- x_all[i] + rnorm(1, mean = 0, sd = dx)   # Gaussian step
  }
  return(cbind(t_all, x_all))
}

set.seed(12)
results_bm_gauss <- replicate(nrep, brownian_gaussian_steps(t.total, dt, dx))

boxplot(x ~ t, data = bm_gauss_long, xlab = "t", ylab = "x", ylim = c(-100, 100))

6B.4 Brownian motion in 2D

The walk generalizes to a plane by drawing an independent Gaussian step for each of \(x\) and \(y\) at every time.

NoteRecipe 6B.4.1

Objective. Simulate Brownian motion in a plane.

Model. A walker at (0, 0) takes an independent Gaussian step in x and in y at each time, x_next = x + N(0, 1)*dx.

Method. Two-dimensional Brownian motion via independent per-axis Gaussian steps.

Test. dx = (1, 1), dt = 1, 10000 steps; seed 12.

Show. A plot of the 2D walk path in the plane.

6B.5 The Wiener process

A precise mathematical description of Brownian motion is the Wiener process \(W_t\), a continuous-time process with four defining properties (Gardiner 2009):

(1) \(W_0 = 0\).

(2) Independent increments: for \(t > 0\) and \(h \geq 0\), the increment \(W_{t+h} - W_t\) is independent of the past \(\{W_s : s < t\}\).

(3) Gaussian increments: \(W_{t+h} - W_t \sim \mathcal{N}(0, h)\).

(4) Continuous paths: \(W_t\) is continuous in \(t\).

Our Gaussian-step walk is essentially a Wiener process. To make the diffusion constant explicit, we scale the step standard deviation as \(\sqrt{2 D \Delta t}\), so that the variance grows as \(2 D t\) regardless of the step size. This scaling is essential: a common mistake is to set the standard deviation to \(\Delta t\).

NoteRecipe 6B.5.1

Objective. Simulate a Wiener process whose variance stays correct regardless of the step size.

brownian_wiener <- function(t.total, dt, D) {
  t_all <- seq(0, t.total, by = dt)
  n_all <- length(t_all)
  x_all <- numeric(n_all)
  step_sd <- sqrt(2 * D * dt)                    # critical scaling
  for (i in 1:(n_all - 1)) {
    x_all[i+1] <- x_all[i] + rnorm(1, mean = 0, sd = step_sd)
  }
  return(cbind(t_all, x_all))
}

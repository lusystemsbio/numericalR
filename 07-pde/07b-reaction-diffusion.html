7B. Reaction-diffusion systems

Author

Mingyang Lu

Adding a reaction term \(f(u, t)\) to the diffusion equation gives a reaction-diffusion equation for a field \(u(X, t)\),

\[ \frac{\partial u(X, t)}{\partial t} = f(u, t) + D \frac{\partial^2 u(X, t)}{\partial X^2} . \tag{1} \]

The reaction term is just the ordinary rate equation of earlier chapters,

\[ \frac{du}{dt} = f(u, t) , \tag{2} \]

and when it vanishes we recover pure diffusion. The two ingredients together, local kinetics plus spatial spreading, produce traveling waves and, later, spatial patterns.

7B.1 Fisher’s equation

Taking logistic growth as the reaction gives Fisher’s equation,

\[ \frac{\partial u}{\partial t} = r u \left( 1 - \frac{u}{B} \right) + D \frac{\partial^2 u}{\partial X^2} , \tag{3} \]

where \(u\) is a population size and \(B\) its carrying capacity. Fisher introduced it to describe the spread of an advantageous gene, with \(u\) the mutant frequency, \(r\) the selection strength, and \(D\) the dispersal rate; it became a foundation of population genetics (Fisher 1937). The integrator is the diffusion solver of Part 7A with the reaction term added at each step (Dirichlet, \(u = 0\) at the ends).

NoteRecipe 7B.1.1

Objective. Simulate Fisher’s equation and see traveling waves of advance.

Model. Fisher’s equation, logistic growth with diffusion, du/dt = r*u*(1 - u/B) + D*d2u/dX2.

Method. The explicit finite-difference reaction-diffusion integrator (a reaction term added to the diffusion step each iteration), with Dirichlet boundaries.

Test. Domain length 100, dX = 1, dt = 0.01, D = 1, r = 0.64, B = 75; a central patch, and separately a left-end patch, each u = 50.

Show. Plots of u(X) at successive times, showing traveling fronts from a central and a left-end patch.

Verification. A local patch grows to carrying capacity and emits two constant-speed fronts, while a left-end patch produces a single rightward traveling wave.

R implementation

# finite-difference step for a reaction-diffusion equation, Dirichlet boundaries
pde_fd_reaction_diffusion <- function(derivs, ngrid, dX, dt, D, t0, t.total, p0, ...) {
  t_all <- seq(t0, t.total, by = dt); nt_all <- length(t_all)
  factor <- D / dX^2 * dt
  p <- p0
  for (i in seq_len(nt_all - 1)) {
    p_plus  <- c(p[-1], 0)
    p_minus <- c(0, p[1:(ngrid-1)])
    f <- sapply(p, function(u) derivs(t_all[i], u, ...))    # reaction at each grid
    p <- p + f * dt + factor * (p_plus + p_minus - 2 * p)
  }
  return(p)
}

fisher <- function(t, u, r, B) r * u * (1 - u / B)

ngrid <- as.integer(l / dX) + 1
X_all <- (0:(ngrid - 1)) * dX

u0[abs(X_all - 50) <= 2] <- 50                 # a patch at the center

u_now <- u0

  u_now <- pde_fd_reaction_diffusion(fisher, ngrid, dX, dt, D, t0 = 0, t.total = 5, p0 = u_now, r = r, B = B)

import numpy as np

def pde_fd_reaction_diffusion(derivs, ngrid, dX, dt, D, t0, t_total, p0, **kwargs):
    t_all = np.arange(t0, t_total + dt, dt); nt_all = len(t_all)
    factor = D / dX**2 * dt
    p = p0.copy()

7B.2 The Fokker-Planck equation

An SDE with drift and (possibly state-dependent) diffusion,

\[ \frac{dX}{dt} = f(X, t) + \sqrt{2 D(X, t)}\, \eta(t) , \tag{4} \]

has a probability distribution \(P(X, t)\) that obeys the Fokker-Planck equation (Gardiner 2009),

\[ \frac{\partial P}{\partial t} = -\frac{\partial (f P)}{\partial X} + \frac{\partial^2 (D P)}{\partial X^2} . \tag{5} \]

This is a reaction-diffusion-like PDE for \(P\), reducing to the plain diffusion equation when \(f = 0\). The new drift term is a first space derivative, which we approximate with a centered difference (again from a Taylor expansion, as in Part 7A),

\[ \frac{\partial F}{\partial X} \approx \frac{F_{i+1}^n - F_{i-1}^n}{2 \Delta X} . \tag{6} \]

For constant \(D\), the explicit update combines this drift term with the familiar diffusion term,

\[ \begin{aligned} P_i^{n+1} = P_i^n &- \frac{\Delta t}{2 \Delta X}\left( f_{i+1} P_{i+1}^n - f_{i-1} P_{i-1}^n \right) \\ &+ D\, \frac{\Delta t}{\Delta X^2}\left( P_{i+1}^n + P_{i-1}^n - 2 P_i^n \right) . \end{aligned} \tag{7} \]

NoteRecipe 7B.2.1

Objective. Solve the Fokker-Planck equation for the distribution of an SDE, rather than averaging many trajectories.

Model. The Fokker-Planck equation dP/dt = -d(f*P)/dX + D*d2P/dX2, tested on the Ornstein-Uhlenbeck well with drift f = -k*X, whose steady state is P_ss(X) = sqrt(k/(2*pi*D))*exp(-k*X^2/(2*D)).

Method. An explicit finite-difference Fokker-Planck integrator: a centered-difference drift term plus the finite-difference diffusion term, with Dirichlet boundaries.

Test. Domain length 100, dX = 1, dt = 0.01, D = 1; springs k = 0.01 and k = 0.03; started from both a localized patch and a uniform distribution.

Show. Plots of P(X) relaxing to the steady-state Gaussian, for each spring stiffness k.

Verification. The distribution relaxes to the analytic steady-state Gaussian from any initial condition, and a stiffer spring confines it to a narrower peak.

R implementation

# finite-difference step for a Fokker-Planck equation (constant D), Dirichlet boundaries
pde_fd_fokker_planck <- function(derivs, ngrid, X_all, dX, dt, D, t0, t.total, p0, ...) {
  t_all <- seq(t0, t.total, by = dt); nt_all <- length(t_all)
  factor   <- D / dX^2 * dt      # diffusion-term scale
  factor_2 <- dt / (2 * dX)      # drift-term scale
  p <- p0
  for (i in seq_len(nt_all - 1)) {
    p_plus  <- c(p[-1], 0); p_minus <- c(0, p[1:(ngrid-1)])
    fp <- sapply(X_all, function(X) derivs(t_all[i], X, ...)) * p   # drift depends on position X
    fp_plus  <- c(fp[-1], 0); fp_minus <- c(0, fp[1:(ngrid-1)])
    p <- p - factor_2 * (fp_plus - fp_minus) + factor * (p_plus + p_minus - 2 * p)
  }
  return(p)
}

We test it on the Ornstein-Uhlenbeck process (a particle in a harmonic well, drift \(f = -kX\), constant noise), whose Fokker-Planck equation is

\[ \frac{\partial P}{\partial t} = -\frac{\partial (-kX P)}{\partial X} + D \frac{\partial^2 P}{\partial X^2} , \tag{8} \]

with the analytic steady state (a Gaussian set by the balance of drift and diffusion)

\[ P_{ss}(X) = \sqrt{\frac{k}{2\pi D}}\, e^{-\frac{k X^2}{2D}} . \tag{9} \]

spring <- function(t, X, k) -k * X

  u_now <- pde_fd_fokker_planck(spring, ngrid, X_all, dX, dt, D, t0 = 0, t.total = 40, p0 = u_now, k = k)

# finite-difference step for a Fokker-Planck equation (constant D), Dirichlet boundaries
def pde_fd_fokker_planck(derivs, ngrid, X_all, dX, dt, D, t0, t_total, p0, **kwargs):
    t_all = np.arange(t0, t_total + dt, dt); nt_all = len(t_all)
    factor   = D / dX**2 * dt     # diffusion-term scale
    factor_2 = dt / (2 * dX)      # drift-term scale
    p = p0.copy()
    for i in range(nt_all - 1):
        p_plus  = np.concatenate((p[1:], [0])); p_minus = np.concatenate(([0], p[:-1]))
        fp = np.array([derivs(t_all[i], X, **kwargs) for X in X_all]) * p   # drift depends on position X
        fp_plus  = np.concatenate((fp[1:], [0])); fp_minus = np.concatenate(([0], fp[:-1]))
        p = p - factor_2 * (fp_plus - fp_minus) + factor * (p_plus + p_minus - 2 * p)
    return p

With the stiffer spring (\(k = 0.03\)) the peak is narrower, and starting from a uniform distribution the system relaxes to the very same steady-state Gaussian, confirming that the Fokker-Planck dynamics forget their initial condition. Solving the PDE for \(P\) is thus a deterministic alternative to averaging many stochastic trajectories from the SDE integrators of Part 6C.
